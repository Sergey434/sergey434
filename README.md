# AI Aggregator

Агрегатор нейросетей: Telegram-бот сейчас, веб-версия следом. Оба работают на одном ядре,
поэтому у пользователя один аккаунт, один баланс и одна история.

```
     Telegram-бот (bot/) ─┐
                          ├─→ Ядро / API (core/) ─→ OpenRouter ─→ GPT, Claude, Gemini, DeepSeek…
     Веб-сайт (web/) ─────┘          │
                          PostgreSQL + Redis
              (пользователи, баланс, диалоги, платежи, лимиты)
```

## Что уже есть

**Ядро (`core/`, FastAPI)**
- Пользователи с автоматической регистрацией и приветственным бонусом
- Каталог моделей и выбор модели пользователем
- Чат с потоковым ответом (SSE) и историей диалогов
- Биллинг: точная стоимость от OpenRouter × наценка, атомарное списание, журнал всех транзакций
- Пополнение с защитой от двойного зачисления
- Лимит запросов в минуту на пользователя (Redis)
- Вход для сайта через Telegram Login (тот же аккаунт, что в боте)
- **Тестовый режим**: без ключа OpenRouter бот отвечает заглушками — можно всё проверить бесплатно

**Бот (`bot/`, aiogram 3)**
- `/start`, выбор модели кнопками, новый диалог, баланс
- Ответ «печатается» по мере генерации, длинные ответы делятся на несколько сообщений
- Пополнение через Telegram Stars
- Под каждым ответом: модель, стоимость, остаток баланса

## Запуск

Нужен сервер (VPS) с Docker.

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Получите ключ на [openrouter.ai/keys](https://openrouter.ai/keys) и пополните там баланс.
   Можно пропустить — тогда бот запустится в тестовом режиме.
3. Настройте окружение:
   ```bash
   cp .env.example .env
   # заполните BOT_TOKEN, OPENROUTER_API_KEY,
   # а SERVICE_TOKEN и JWT_SECRET сгенерируйте: openssl rand -hex 32
   ```
4. Проверьте модели и цены в `core/app/catalog.py` — сверьте с [openrouter.ai/models](https://openrouter.ai/models).
5. Запустите:
   ```bash
   docker compose up -d --build
   docker compose logs -f bot
   ```
6. Напишите боту `/start`.

## Настройка экономики (`.env`)

| Параметр | Смысл |
|---|---|
| `USD_RUB_RATE` | Курс для пересчёта цен провайдера в рубли |
| `MARKUP` | Наценка. `2.0` = пользователь платит вдвое больше вашей себестоимости |
| `WELCOME_BONUS_KOPECKS` | Бонус новому пользователю (в копейках) |
| `KOPECKS_PER_STAR` | Сколько копеек баланса даёт 1 звезда Telegram |
| `STARS_PACKS` | Варианты пополнения в звёздах |
| `RATE_LIMIT_PER_MINUTE` | Лимит запросов на пользователя |

Наценка должна покрывать комиссии (Telegram забирает часть стоимости звёзд при выводе),
налоги, курсовые колебания и прибыль. Пересчитайте свою экономику до запуска рекламы.

## Разработка

```bash
cd core
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
pytest          # тесты на SQLite, без Postgres/Redis
```

Документация API ядра: `http://localhost:8000/docs` после запуска.

## Структура

```
core/app/
  main.py         — точка входа FastAPI
  config.py       — все настройки из .env
  models.py       — таблицы БД
  catalog.py      — модели и цены
  llm.py          — клиент OpenRouter (потоковый)
  billing.py      — расчёт стоимости, списание, пополнение
  ratelimit.py    — лимиты запросов
  auth.py         — авторизация бота и сайта
  routers/        — HTTP-методы: chat, account, internal
bot/app/
  main.py         — запуск бота
  handlers.py     — команды, кнопки, оплата, диалог
  core_api.py     — клиент к ядру
web/              — сюда пойдёт сайт (см. web/README.md)
```
